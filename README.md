# LEMP-wordpress-homelab
Production-style deployment of WordPress on a LEMP stack for learning Linux system administration and web hosting operations.

## Stack
- Ubuntu Server (connected via SSH from macOS)
- nginx
- MariaDB
- PHP-FPM
- WordPress (manual installation)

## What I implemented
- Full LEMP stack installation and configuration
- nginx virtual host with PHP-FPM integration
- Dedicated MariaDB database and least-privilege database user
- Manual WordPress installation and configuration
- File ownership and permission hardening
- Basic firewall (UFW) and systemd service management
- Project documentation

## Skills demonstrated
- Linux system administration
- Web server configuration (nginx)
- Database administration (MariaDB)
- PHP-FPM integration
- Secure web application deployment
- Troubleshooting and operational documentation

## Structure
- `docs/` – Setup notes
- `nginx/` – Example virtual host configuration
- `notes/` – Permission hardening and operational notes
